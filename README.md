# Library of Worlds

Library of Worlds is a living digital library where every book feels alive. Some stories stay with you forever, while others visit for just a while — inspired by Marvel’s multiverse.



---
## **Project Description**

A comprehensive book store management system that allows users to browse, purchase, and borrow books. The platform supports user authentication, subscription plans, and administrative features for managing books and categories.

---
## **Features**

- User registration and authentication
- Browse and search books by category
- Purchase books for permanent access
- Borrow books for temporary access
- Subscription plans (category-based and limited access)
- User library management
- Admin dashboard with analytics
- File upload and management

---
## **Tech Stack**
- **Backend:** [Node.js](https://nodejs.org/) + [Express.js](https://expressjs.com/)
- **Database:** [MongoDB](https://www.mongodb.com/)
- **Authentication:** JWT (JSON Web Tokens)
- **File Storage:** Cloudinary & Internal Storage
- **Testing:** Jest

---
## **Installation & Setup**

1. Clone the repository
```bash
git clone <repository-url>
cd Book-Store
```

2. Install dependencies
```bash
npm install
```

3. Create `.env` file with your configuration
```bash
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
CLOUDINARY_CLOUD_NAME=your_cloudinary_name
CLOUDINARY_API_KEY=your_cloudinary_key
CLOUDINARY_API_SECRET=your_cloudinary_secret
```

4. Start the server
```bash
npm start
```
